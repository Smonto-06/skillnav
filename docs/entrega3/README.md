## Cómo subir un archivo

Entrar a esta carpeta en GitHub, usar **Add file → Upload files**, arrastrar el
archivo y confirmar con **Commit changes**. Al estar ya dentro de la carpeta no
hace falta escribir ninguna ruta.

Cada integrante sube su propio archivo desde su cuenta: el historial de GitHub
registra quién aportó cada cosa.
